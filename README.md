# Wilian Nunag — Portfolio

Personal portfolio of Wilian Nunag, a BSIT student at National University – Clark who builds and tests web and mobile apps.

## Stack

React + Vite + TypeScript, Tailwind CSS, shadcn/ui, React Router, three.js. Hosted on Cloudflare Pages.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Checks

```bash
npm run lint
npm run typecheck
npm run test
```
